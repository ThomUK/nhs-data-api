# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-11-17

## Context

This is a solo project that may grow into something larger. Decisions made now will be
questioned later, by me, by collaborators, or by procurement reviewers. They need to be
traceable.

## Decision

Keep lightweight ADRs in `docs/adr/`, one decision per file, numbered sequentially.

## Consequences

- Cheap to write, easy to review in pull requests.
- Superseded decisions remain as history rather than being edited away.
