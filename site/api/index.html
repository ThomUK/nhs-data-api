secondthursday

Public NHS England performance statistics through a modern JSON API, designed for human programmers and AI agents alike. Every number comes back with its definition, the publication it came from, its licence, and the caveats that apply.

Reconciled with NHS England. For September 2026, all 4,004 provider × specialty rows match NHS England's published provider figures (waiting list, waits over 18/52/65/78 weeks, median and 92nd percentile). Reconciliation runs every month before release.

Principles

  • Citable. Each response's meta block names the dataset, source page, licence and attribution, and defines every measure returned.
  • Honest about the data. Known problems (missed submissions, mergers, recodes, revisions) are returned as caveats rather than hidden. Missing data is never a zero.
  • Matches the publisher. Measures reproduce NHS England's published figures exactly, on NHS England's basis.
  • Open data only. Every dataset is published under the Open Government Licence; reuse is permitted with attribution.

The API is not yet publicly deployed. Examples use https://<api-host> as a placeholder for the host.

Concepts

Views

Waiting-list data can be grouped by who treats patients or by where they live:

  • national: England
  • provider: Provider
  • provider_icb: Provider's ICB
  • population_icb: Population (ICB)
  • population_sub_icb: Population (sub-ICB location)

Population views answer "how long are this area's residents waiting, wherever they are treated?".

Responses

{
  "data": [ { "period": "2026-09-01", "org_code": "RJ1", "waiting_list_total": 107635, ... } ],
  "meta": {
    "dataset": "rtt",
    "source_page": "https://www.england.nhs.uk/statistics/...",
    "licence": "Open Government Licence v3.0",
    "attribution": "Source: NHS England, ...",
    "caveats": [ { "id": "rtt-no-estimates", "text": "..." } ],
    "measures": { "waiting_list_total": { "label": "...", "unit": "count", "definition": "..." } }
  }
}

Periods are ISO dates for the first day of the month. Organisations use ODS codes. Measure ids are stable; see Datasets & measures.

Revisions and missing data

NHS England revises earlier months. The API serves the latest version of each month and keeps every version. A provider that did not submit has no row for that month (never a zero); /v1/rtt/submissions lists who did not submit and why (merged or recoded, closed, or missing).

Like-for-like changes

Month-on-month changes come in two forms: the simple difference of published totals, and a like-for-like version that only compares providers present in both months, following mergers and recodes. In September 2026 the published waiting list fell by 83,840, but the like-for-like change was a rise of about 5,500: Nottingham University Hospitals did not submit.

For AI agents

A plain-text summary for language models is at llms.txt. The full spec is openapi.json. Agents should quote meta.attribution when citing figures and pass on any meta.caveats. An MCP server exposing the same endpoints as task-shaped tools is planned.
