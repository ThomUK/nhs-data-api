Endpoints

All endpoints are read-only GET requests returning JSON with a data array or object and a meta block. The machine-readable spec is openapi.json (OpenAPI 3.1.0).

  • /v1/datasets: Datasets available, with status, frequency and a short summary.
  • /v1/datasets/{dataset_id}: Full catalogue entry for one dataset: measures, views, dimensions, codes and caveats.
  • /v1/rtt/metrics: RTT v1 measures for one view, filtered by organisation, period and specialty.
  • /v1/rtt/submissions: Providers submitting each month; why last month's providers are missing (merged or
  • /v1/organisations: Organisations that appear in the statistics, from the ODS snapshot.
  • /v1/organisations/{org_code}: One organisation, with ODS successor/predecessor links and curated lineage links.

GET/v1/rtt/metrics

RTT v1 measures for one view, filtered by organisation, period and specialty.

ParameterInTypeDefaultDescription
viewquerystringproviderprovider / provider_icb: where patients are treated. population_icb / population_sub_icb: where patients' care is commissioned (residents, wherever treated). national: England.
One of: national, provider, provider_icb, population_icb, population_sub_icb
orgquerystringODS code within the view, e.g. RJ1 or QKK
periodquerystringMonth as YYYY-MM-01; default latest
period_fromquerystringStart of a range (inclusive)
treatment_functionquerystringC_999Treatment function code; C_999 = all
measuresquerystringComma-separated measure ids; default all
include_experimentalquerybooleanFalseInclude experimental measures
